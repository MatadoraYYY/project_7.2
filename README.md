# Персональные промо-предложения (Dynamic Pricing)

Проект №7.2. Коммерческий прототип системы генерации персональных промо-предложений
для клиентов на основе их сегмента и ценовой чувствительности (эластичности),
вместо массовых скидок "всем одинаково".

## Возможности

- Расчёт ценовой эластичности клиента на основе истории покупок.
- Детерминированная (rule-based) сегментация: `new_user`, `repeat_buyer`, `vip`, `dormant`, `price_sensitive`.
- Offer Engine: генерация и прозрачный скоринг топ-3 персональных офферов с объяснением причины.
- REST API на FastAPI с автоматической документацией (`/docs`, `/redoc`).
- Веб-дашборд (HTML/CSS/JS): клиенты, офферы, A/B-тест.
- A/B-сравнение персонализированных офферов и массовых промо (на синтетических данных).
- 25 unit- и интеграционных тестов (pytest).
- Docker/Docker Compose для продуктивного развёртывания.
- Защита: rate limiting, API-key на write-эндпоинтах, никаких PII в схеме данных.

## Быстрый старт (локально)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

# Наполнить синтетическими данными (150 анонимных клиентов)
python -m scripts.seed_synthetic_data

# Смоделировать генерацию офферов и конверсии для A/B-теста
python -m scripts.simulate_offer_cycle

# Запустить сервер
uvicorn app.main:app --reload
```

Открыть:
- API документация: http://localhost:8000/docs
- Дашборд: http://localhost:8000/app/
- Health check: http://localhost:8000/health

## Запуск через Docker

```bash
export APP_SECRET_KEY=$(openssl rand -hex 32)
docker compose up --build
```

## Тесты

```bash
pytest tests/ -v
```

25 тестов покрывают расчёт эластичности, сегментацию, offer engine и API (customers, offers).


## Ограничения и допущения

Проект использует **синтетический обезличенный набор данных**. Персональные данные
реальных клиентов не собираются и не хранятся — только анонимные идентификаторы
(`external_ref`). Результаты A/B-теста и оценки маржинальности являются учебной
демонстрацией методики измерения эффекта персонализации, а не подтверждённым
бизнес-результатом. Для использования в реальном бизнесе необходимы: pilot-проект
с контрольной группой, фактические транзакционные данные, согласование с юристами
по обработке персональных данных, и калибровка констант маржи с финансовым отделом.

## Формула ценовой эластичности

E = -(ΔQ/Q) / (ΔP/P), где ΔQ/Q — относительное изменение количества покупок,
ΔP/P — относительное изменение цены. Результат ограничен диапазоном [0.3, 2.0].
